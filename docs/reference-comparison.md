驗證集有 39 個完整批次及最後 16 筆，共 40 批。令各批指標為 `m_i`、樣本數為 `n_i`：原算法為 `Σm_i / 40`，依樣本數加權則為 `Σ(n_i × m_i) / 10000`。最後一批在兩者中的權重分別是 2.5% 與 0.16%，因此即使同一模型，兩種 loss／accuracy 也可能不同。原作者還會打亂驗證資料，最後 16 筆的組成會改變。比較時須對照相同算法，並保留加權指標供判讀。

本實作刻意固定種子 42、關閉驗證集打亂，以 `num_workers=0` 支援不同平台，且只在 CUDA 啟用 `pin_memory`。驗證採用 `eval()` 與 `inference_mode()`，另加入官方 10,000 筆測試集；新增的測試成績須與上述驗證基準分開閱讀。原作者未提供種子與完整環境版本，因此無法保證逐位相同。
